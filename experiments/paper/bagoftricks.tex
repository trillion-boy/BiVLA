\section{Bag of Tricks}

A VLA policy $\pi_\theta$ maps an observation $o_t$, the image $I_t$ and the
instruction $l$, through a visual encoder and a decoder of $N$ transformer
layers to an action $a_t \in \mathbb{R}^7$, six pose components and a binary
gripper decision. Chunking backbones return $c$ actions per query and an
action repeat $r$ holds each for $r$ control steps, so one query advances the
environment by $h = c\,r$. Every intervention below leaves $\theta$ frozen.
Calibration selects inference-time quantities only, the removed layers,
thresholds, budgets, and keyframe intervals, and never updates a parameter.
The reference is the released policy run unchanged under fused attention, and
each intervention perturbs one part of it.

\subsection{Negative Controls}

\emph{Fixed foveation} keeps a sharp fovea and suppresses the periphery at a
keep fraction $\rho$, default $0.2$. The log-polar variant warps the frame
about its center, keeps a fraction $\rho$ of the samples, interpolates back to
full size, and inverts the warp. The blur variant keeps a central disc of
radius $r_s = \sqrt{\rho HW/\pi}$ and blends increasingly blurred copies
outside it. Both leave the output resolution and the visual token count
unchanged, so foveation controls for the claim that perceptual simplification
alone accelerates inference.

\emph{Unconditional action repeat} executes a dense action for $k$ consecutive
steps, $\tilde a_{t+j} = a_t$ for $j = 0, \dots, k-1$, with $k = 2$ by default,
and queries the policy on none of the repeated steps. It divides model calls by
$k$ and multiplies by $k$ the interval the robot acts on without fresh
feedback, so it controls for skipping feedback without a safety gate.

\subsection{Recent Baseline}

\emph{VLA-Cache}~\cite{vlacache} reuses the cached key-value computation of
visually static patches and recomputes the dynamic and task-relevant ones, the
latter selected from a language-model attention layer. History is retained,
unlike under token dropping. We run the released implementation as the recent
training-free baseline, not as a method of ours.

\subsection{Conditional Candidates}

\emph{Calibrated depth removal} scores each decoder block $j$ by the ShortGPT
block influence $s_j = 1 - \operatorname{mean}_q \cos(H^{\mathrm{in}}_{j,q},
H^{\mathrm{out}}_{j,q})$~\cite{shortgpt}, averaged over a calibration split
disjoint from the test episodes. The selector protects the first quarter of
the stack and the final block, forbids removing two adjacent blocks, and
freezes the chosen indices before testing. Selected blocks are removed
structurally and the generation cache is reindexed, so this is true removal
rather than an identity block. We evaluate budgets of 0, 1, 2, and 4 blocks
and treat one as the conservative operating point.

\emph{Guarded action reuse} makes the action-repeat saving conditional. A
cheap signature $S_t$ samples every eighth pixel. Reuse requires whole-frame
stability $\operatorname{mean}|S_t - S_{t-1}| \le \tau_g$ and local stability
$\max_p \operatorname{mean}_{x \in p}|S_t(x) - S_{t-1}(x)| \le \tau_l$ over an
$8 \times 8$ grid, defaults $\tau_g = 0.01$ and $\tau_l = 0.03$. It also
requires the two most recent dense actions to agree,
$\cos(a^{0:6}_{t-2}, a^{0:6}_{t-1}) \ge 0.995$, a translation norm above
$0.01$, and matching gripper signs. Reuse is capped at one consecutive step
and any failed gate falls back to dense inference, so every step still sees a
current image. We sweep the thresholds as strict, moderate, and aggressive.

\emph{Interaction-aware temporal fusion} forms one patch mask and uses it for
both representation fusion and cache reuse. For each visual patch it computes
motion $m_i$, image entropy $e_i$, and optional text-to-vision relevance
$r_i$, protects patches high in any of these or adjacent to one, and among
the rest marks at most half reusable by the rank $R_i = m_i + e_i + r_i$. A
reusable patch takes the previous step's projected token and the others are
recomputed, with a dense keyframe every third step to bound propagation. The
same reusable indices drive selective key-value reuse, the speed mechanism
paired with the fusion hypothesis. We evaluate motion-entropy, task-aware, and
conservative-adaptive settings. Fusion alone runs the full network and is an
accuracy candidate, and the selective-cache path is the extension that must
clear the latency gate.
